# 🎓 SkillSphere – Online Learning Platform

## 🌐 Live URL

🔗 https://skillsphere.mkkhalid.top/

---

## 📌 Project Overview

**SkillSphere** is a modern online learning platform where users can explore skill-based courses, view detailed course content, and manage their learning journey.

The platform focuses on providing **accessible, practical, and career-oriented education**, helping users build real-world skills in areas like web development, design, and more ([Skills Sphere][1]).

---

## 🎯 Purpose

The goal of this project is to:

* Provide a centralized platform for online learning
* Help users gain **practical and job-ready skills**
* Offer a smooth and modern UI/UX experience
* Implement authentication and protected routes
* Build a scalable full-stack learning system

---

## 🚀 Key Features

### 🔐 Authentication System

* User login & registration
* Session management
* Protected routes (course details page access only after login)

### 📚 Course Management

* Browse all available courses
* View course details (title, instructor, duration, rating, etc.)
* Static curriculum display

### 👤 User Profile

* View logged-in user info
* Profile image display
* Logout functionality

### 🎨 Modern UI/UX

* Responsive design (mobile + desktop)
* Animated navbar using Framer Motion
* Blur + glassmorphism navbar effect

### 🔎 Navigation System

* Active link highlighting
* Smooth routing using Next.js

## 🔒 Protected Route Logic

* If user is **not logged in** → redirect to login
* After login → redirect back to intended page
* Only authenticated users can access course details
